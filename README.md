# YouTrack on rootless Podman (same pattern as pihole-podman)

YouTrack runs as your normal user via a Podman Quadlet systemd unit. Only one
one-time step needs sudo: installing Podman.

## Setup on a new machine
```bash
./setup-host.sh                 # once, asks for sudo
cp .env.example .env             # set YOUTRACK_HOST/YOUTRACK_PORT
./install.sh                    # no sudo
loginctl enable-linger $USER    # once, so it survives a reboot without login
```
- Open: `http://<YOUTRACK_HOST>:<YOUTRACK_PORT>`

## Daily use
| Task      | Command |
|-----------|---------|
| Status    | `systemctl --user status youtrack` |
| Logs      | `journalctl --user -u youtrack -f` |
| Restart   | `systemctl --user restart youtrack` |
| Update    | `./install.sh` |
| Remove    | `./uninstall.sh` (add `--purge` to delete data) |

## Backup

Backups are saved in `~/.local/share/youtrack/backups/`. Sync that folder to
Google Drive yourself. Backup rotation: 1.

## Restore

1. Copy the backup file from Google Drive into `~/.local/share/youtrack/backups/`.
2. Run:

```bash
./install.sh
```

3. Open the URL printed by the script.
4. Use the Configuration Wizard to restore the backup.
5. Use the same or a newer YouTrack version.

## Why systemd instead of podman-compose

`podman-compose up -d` only starts the container while you run it — nothing
brings it back after the machine reboots. The Quadlet unit
(`~/.config/containers/systemd/youtrack.container`, generated by
`install.sh` from [youtrack.container.in](youtrack.container.in)) has
`Restart=always` and `WantedBy=default.target`, so systemd starts it at boot
and restarts it if it crashes — same approach as
[pihole-podman](../pihole-podman). `loginctl enable-linger` is what lets your
user's systemd instance (and this unit) start at boot even without logging in.

## Notes
- If your host IP or port changes, edit `.env` and run `./install.sh` again.
- Needs Podman 4.4 or newer (`podman --version`).

## Where things live
- Service file: `~/.config/containers/systemd/youtrack.container`
- Data: `~/.local/share/youtrack/{data,conf,logs,backups}`
